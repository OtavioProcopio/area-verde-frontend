# Area Verde Frontend

Estrutura do repositório:

- `.devcontainer/` e `.vscode/` na raiz para padronizar o ambiente de desenvolvimento
- `app/` com todo o código executável do frontend

O protótipo original veio do AI Studio. Os artefatos temporários desse fluxo foram removidos para deixar a base pronta para evoluir rumo à integração real com a `area-verde-api`.
